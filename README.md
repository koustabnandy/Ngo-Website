# 🌍 NGO Website

A responsive website built for an NGO to showcase its mission, services, and donation options.  
The project focuses on **user-friendly design, accessibility, and clear navigation** to spread awareness and encourage community participation.

---

## 🚀 Features
- 🏠 **Homepage** with NGO’s mission and introduction  
- 📑 **About Section** describing activities and objectives  
- 📷 **Gallery/Events** to highlight past and upcoming initiatives  
- 💳 **Donation Section** (placeholder / integrated option if applicable)  
- 📞 **Contact Form** for communication and volunteering  
- 📱 **Responsive Design** for mobile, tablet, and desktop  

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript  
- **Framework:** Bootstrap (for responsive UI)  
- **Other Tools:** FontAwesome, Google Fonts
